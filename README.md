# ЛР №2 — поиск по документам

Вариант 3: «Кулинарная энциклопедия».

## Что делает программа

`lab2.py` запускает весь конвейер: читает документы и запросы, делает базовый поиск, строит TF-IDF + cosine similarity, сравнивает 4 конфигурации предобработки, считает Hit@5 и MRR@5 на 8 открытых запросах, сохраняет результаты и разбор ошибок.

## Конфигурации

- A — без лемматизации, стоп-слова остаются, униграммы;
- B — с лемматизацией, стоп-слова остаются, униграммы;
- C — с лемматизацией, стоп-слова удаляются, униграммы;
- D — с лемматизацией, стоп-слова удаляются, униграммы + биграммы.

## Структура проекта

- `lab2.py` — основной скрипт (точка входа);
- `baseline.py` — базовый поиск по совпадению слов;
- `preprocess.py` — очистка и лемматизация текста;
- `tfidf.py` — векторизация и косинусное сходство;
- `task5.py` — запуск четырех конфигураций;
- `serch.py` — метрики и разбор ошибок;
- `reading_files.py` — чтение CSV;
- `db/` — исходные данные (documents, queries, dev_relevance);
- `output/` — папка для результатов.

## Запуск

```bash
python lab2.py
```

Перед запуском папка output/ должна существовать.
